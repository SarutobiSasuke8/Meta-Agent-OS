# Cartographer Validator

## Purpose

Validate the Cartographer output before advancing.

## Required Checks

- [ ] Output file exists.
- [ ] Output follows the required schema.
- [ ] Objective is clear.
- [ ] Inputs used are listed.
- [ ] Findings are specific.
- [ ] Assumptions are stated.
- [ ] Risks are stated.
- [ ] Open questions are stated.
- [ ] Recommended next action is clear.
- [ ] Files created or updated are listed.
- [ ] Output is useful to the next stage.
- [ ] Output does not violate stage gates.

## Pass Standard

The next persona can use this output without asking the same basic questions again.

## If Failed

Revise the output before advancing.
