# Orchestrator Runtime Log Schema

Required sections:

1. Runtime Objective
2. Selected Mode
3. Active Personas
4. Routing Decisions
5. Inputs Used
6. Actions Taken
7. Handoffs
8. Outputs Produced
9. Quality Check
10. Issues Encountered
11. Improvements Recommended
12. Files Created Or Updated

Required quality:
- No external action unless approved.
- Log routing decisions clearly.
