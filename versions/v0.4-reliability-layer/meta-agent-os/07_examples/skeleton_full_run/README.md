# Skeleton Full Run Example

## Purpose

This folder shows what a completed Meta Agent OS run should roughly look like.

It is intentionally skeletal. Use it as a shape reference, not as content to copy blindly.

```text
Oracle → Sophia → Cartographer → Architect → QS → Guardian → Builder → Evaluator → Orchestrator → Librarian
```

## Why This Exists
