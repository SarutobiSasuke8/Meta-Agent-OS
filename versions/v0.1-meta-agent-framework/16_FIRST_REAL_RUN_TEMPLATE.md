```text

CARTOGRAPHER_WORKFLOW_MAP.md
```

```text
Run The Architect using all prior outputs.

Create at least three architecture variants:
1. Lightweight version
2. Balanced version
3. Advanced version

ARCHITECT_SYSTEM_DESIGN.md
```
