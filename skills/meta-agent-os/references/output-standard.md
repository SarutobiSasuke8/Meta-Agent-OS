# Output Standard

## Required Handoff

Every major Meta Agent OS output should include:

- Objective
- Inputs used
- Findings
- Assumptions
- Risks
- Open questions
- Recommended next action
- Files created or updated

## Quality Bar

Good outputs are specific, repo-grounded, structured, useful to the next stage, honest about uncertainty, and clear about assumptions and risks.

Reject or revise outputs that are generic, vague, overconfident, missing file paths, missing next actions, or full of agent theatre instead of operational findings.

## Memory Placement

- Project context: `meta-agent-os/05_memory/project_brain.md`
- Decisions: `meta-agent-os/05_memory/decision_log.md`
- Assumptions: `meta-agent-os/05_memory/assumptions_log.md`
- Changes: `meta-agent-os/05_memory/changelog.md`
- Stage outputs: `meta-agent-os/03_outputs`

## Evidence Rules

Separate facts from assumptions. Cite local files when possible. State what would validate uncertain claims.
